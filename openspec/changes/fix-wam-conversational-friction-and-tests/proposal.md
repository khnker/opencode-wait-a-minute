# Proposal: Fix WAM Conversational Friction and Add Real Integration Tests

## Why
Analysis across all workspace projects reveals recurring conversational comprehension gaps, pragmatic misinterpretations of user frustration, and rigid state gating that causes unnecessary task re-initialization and loop friction.

## What Changes
1. Flexible intent recognition for conversational state transitions (handling informal user prompts and frustration without blocking on strict contract approvals).
2. Pragmatic tone adaptation in message handlers.
3. Real integration test suite simulating WAM-enabled OpenCode sessions with conversational friction scenarios.
