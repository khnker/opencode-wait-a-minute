# autonomy-suite-baseline

## ADDED Requirements

### Requirement: Capability baseline is deterministic and current

The committed prompt-eval baselines MUST be produced by the repository freezer and MUST be
byte-for-byte reproducible. A stale baseline MUST be regenerated by the freezer rather than
edited by hand.

#### Scenario: Delegation hash is current

- **WHEN** the baseline test serializes `buildBaseline()` twice
- **THEN** both serializations are byte-identical
- **AND** every committed baseline matches the generated output
- **AND** the only hash change relative to the previous commit is `injection.delegation`
  in `core.json` and `delegation.json`

### Requirement: Task delegation is governed as GUARDED

The `task` tool MUST be classified as GUARDED by the explicit catalog, MUST NOT appear in
`OUT_OF_SCOPE_TOOLS`, and MUST NOT be downgraded to SAFE by `getEffectiveCapability`.

#### Scenario: Effective capability of task

- **WHEN** `getEffectiveCapability("task")` and `evaluateAction("task", …)` are evaluated
- **THEN** both report `GUARDED`
- **AND** `isMutatingCapability("task")` is `true`

### Requirement: Delegation meta-tools stay out of scope

`compress`, `delegate_task`, `call_agent` and `skill` MUST remain in `OUT_OF_SCOPE_TOOLS`,
resolve to SAFE through `getEffectiveCapability`, and bypass the fail-closed envelope.

#### Scenario: Meta-tools bypass fail-closed

- **WHEN** each delegation meta-tool is evaluated by `getEffectiveCapability` and
  `evaluateAction`
- **THEN** the effective capability is `SAFE`
- **AND** the action is not treated as mutating

### Requirement: Zero-friction assertion matches current advisory wording

The zero-friction injection test MUST assert the current advisory contract: the main session
may edit/write inline without asking permission, with no `BLOQUEADA` marker.

#### Scenario: Advisory prompt assertions

- **WHEN** the `injection.delegation` prompt is loaded
- **THEN** it matches `puede editar/escribir inline` and `sin pedir permiso`
- **AND** it does not match `BLOQUEADA`
