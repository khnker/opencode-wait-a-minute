# Benchmark Results

## RC1 Benchmark

The RC1 benchmark measures effective input reduction across a standardized task suite.

### Results

- Baseline effective input: 225,077 tokens
- WAM effective input: 129,720 tokens
- Net input saved: 95,357 tokens
- Reduction: 35.94%
