# Benchmark Results

This page reports the RC1 numbers **exactly as they appear** in
`benchmarks/reports/rc1/`. It does not invent a single "token reduction"
headline. Read [limitations.md](./limitations.md) before quoting any figure.

## Source of truth

Sections A and B1 come from `benchmarks/reports/rc1/metrics.json`, generated by
`npm run report:rc1` and content-hashed in `manifest.json`. Section B2 comes
directly from a one-off real-provider run recorded in
`benchmarks/results/2026-10-07T19-55-09.328Z/real-report.json`; it is **not** part
of the committed RC1 bundle.

## A. Internal — deterministic

Harness: `benchmarks/validation/*` (no provider, no network).

| Metric | Value |
| --- | --- |
| Snapshot cases | 10 |
| Snapshot passed | 10 |
| Snapshot failed | 0 |
| Fast-path count | 34 |
| Context rebuilds | 8 |
| Turns | 42 |
| Total reduction | **69.6%** |

This figure measures context reconstruction on a deterministic snapshot harness.
It is **not** a real-model saving and must not be quoted as one.

## B. Empirical — real harness

Harness: `benchmarks/run-real.mjs` (mock provider by default; OpenAI-compatible
provider when credentials are set).

### B1. Dry-run (shipped default)

| Metric | Value |

| Baseline input tokens | 195 |
| WAM input tokens | 420 |
| Total tokens | 600 |
| Rebuilds | 30 |
| Outcome match | 0 / 30 |
| Non-equivalent | 30 |

| WAM overhead | 0 tokens |

In the shipped dry-run configuration, WAM overhead exceeds the baseline context
it replaces, so `netInputSavings` is **negative**. This is reported as-is. It is
**not** combined with section A.

### B2. Real provider run (credentialed, one-off)

Run: `benchmarks/results/2026-10-07T19-55-09.328Z/` — provider
`openai-compatible`, model `cost-saver`, 39 turns / 24 scenarios (2026-10-07).

| Metric | Value |
| --- | --- |
| Baseline input tokens | 186,364 |
| WAM input tokens | 41,327 |
| WAM overhead tokens | 84,292 |
| WAM effective input | 125,619 |
| Net input savings | **60,745 tokens** (32.6% of baseline) |
| Context rebuilds | 54 |
| Fast-path count | 11 |
| Turns | 39 |
| Trials | 24 |
| Non-equivalent turns | 0 |
| State equivalent | true |
| Outcome match | 0 / 39 |
| SuccessRate | 0% |
| EquivalenceRate | 0% |

Unlike the dry-run, this real run has **positive** net input savings. Caveats:

- **Single trial** (`trials = 1`): no confidence interval is meaningful.
- `Outcome match`, `SuccessRate` and `EquivalenceRate` are **0** because every
  turn's correctness fell back (`correctnessSource: "fallback"`,
  `verification: null`). The harness produced no verification signal, so these
  three figures are **not** a model-quality verdict — do not quote them as one.
- The run is **not reproduced in CI** and depends on the provider, model version
  and pricing at run time (see [limitations.md](./limitations.md)).
- The harness's own `metrics` percentages (`context_reduction` /
  `net_input_savings`) use a per-scenario aggregation and may differ slightly
  from the raw token counts above.

## What is NOT claimed

- No single merged "token reduction %" is published.
- The `internalDeterministic` reduction (69.6%), the dry-run `empiricalReal` net
  savings (-225 tokens) and the real-provider run (B2) are **not** a
  like-for-like comparison.
- No currency figure is published; provider pricing is never applied.
