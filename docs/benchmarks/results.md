# Benchmark Results

This page reports the RC1 numbers **exactly as they appear** in
`benchmarks/reports/rc1/`. It does not invent a single "token reduction"
headline. Read [limitations.md](./limitations.md) before quoting any figure.

## Source of truth

The numbers below come from `benchmarks/reports/rc1/metrics.json`, which is
generated by `npm run report:rc1` and content-hashed in `manifest.json`.

## A. Internal — deterministic

Harness: `benchmarks/validation/*` (no provider, no network).

| Metric | Value |
| --- | --- |
| Snapshot cases | 10 |
| Snapshot passed | 10 |
| Snapshot failed | 0 |
| Fast-path count | 34 |
| Context rebuilds | 8 |
| Turns | 42 |
| Total reduction | **69.6%** |

This figure measures context reconstruction on a deterministic snapshot harness.
It is **not** a real-model saving and must not be quoted as one.

## B. Empirical — real harness (dry-run by default)

Harness: `benchmarks/run-real.mjs` (mock provider unless credentials are set).

| Metric | Value |
| --- | --- |
| Baseline input tokens | 195 |
| WAM input tokens | 420 |
| Total tokens | 600 |
| Rebuilds | 30 |
| Outcome match | 0 / 30 |
| Non-equivalent | 30 |
| Context reduction | **-225 tokens** |
| WAM overhead | 0 tokens |
| Net input savings | **-225 tokens** |
| Invalid comparisons | 0 |

In the shipped dry-run configuration, WAM overhead exceeds the baseline context
it replaces, so `netInputSavings` is **negative**. This is reported as-is. It is
**not** combined with section A.

## What is NOT claimed

- No single merged "token reduction %" is published.
- The `internalDeterministic` reduction (69.6%) and the `empiricalReal` net
  savings (-225 tokens) are **not** a like-for-like comparison.
- No currency figure is published; provider pricing is never applied.
