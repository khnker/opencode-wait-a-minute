# Requirements

## What are requirements in WAM?

Requirements are the user's needs expressed in a task request. WAM separates:
- **Functional requirements**: What the agent should do
- **Non-functional requirements**: How it should be done (performance, constraints)
- **Assumptions**: Things taken for granted
- **Unknowns**: Information needed to proceed

## Requirement states

Requirements can be:
- **Known**: Verified facts from repository or user
- **Assumed**: Believed true without verification
- **Unknown**: Need to be discovered
- **Clarified**: Resolved through questioning
