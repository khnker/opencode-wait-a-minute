# Assumptions

## What are assumptions in WAM?

Assumptions are beliefs taken as true without verification. WAM tracks assumptions to:
- Surface hidden risks
- Prompt for clarification when critical
- Prevent incorrect actions

## Assumption types

- **Repository assumptions**: About structure, dependencies, configurations
- **User intent assumptions**: About what the user wants
- **Environment assumptions**: About available tools, versions, permissions
- **Knowledge assumptions**: About the agent's own capabilities
