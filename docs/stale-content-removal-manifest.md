# Stale content removal manifest

This manifest is the explicit target list required by decision D1 for the
"remove no-ops, duplication and stale content" cleanup. It is scoped to the
committed tracked tree (decision D2). Untracked workspace scratch is out of
scope and must be handled in a separate, owner-confirmed pass.

## Evidence used to classify a path

- The path is generated by test/benchmark runs (cache, temp fixtures, task
  snapshots), not authored source.
- No tracked source, script, test, package manifest or OpenSpec artifact
  references the path.
- The path is not part of the `dist/` build mirror contract (the mirror is
  intentional and regenerated by `scripts/build.mjs`).
