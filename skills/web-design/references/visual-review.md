# Visual Review Reference

## Review Gates
- Non-compensating evaluation: critical failures in accessibility, layout hierarchy, or semantic token usage cannot be averaged away by visual decoration.
- Contrast verification: ensure text and UI components meet WCAG 2.1 AA standards.
- Hierarchy check: primary actions must be immediately identifiable above secondary and tertiary actions.
- Spacing verification: padding and margins must derive from the project design system grid.

## Evidence Requirements
- When visual verification is available, screenshot evidence or structured layout validation output is required.
- When unavailable, explicit reporting of verification constraints must be recorded in the task summary.
- Flag any drift between `DESIGN.md` specification and actual implementation values.
