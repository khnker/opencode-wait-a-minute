# Design Context Reference

Source: ContextSrc/docs/design-context.md (CONSENSUS)

## Purpose
Establishes project-level design grounding and cross-session persistence via `DESIGN.md`.

## Principles
1. Read `DESIGN.md` at `<projectRoot>/DESIGN.md` before every UI task.
2. Ground all component styling in declared semantic tokens rather than raw values.
3. When starting a new application without brand info, ask material questions (identity, primary user, visual direction references) rather than silently inventing identity.
4. Maintain consistency across sessions by persisting spacing, typography, and surface rules.
