# Design Critique

Evaluate whether the interface works as a designed experience, not only technically; score
findings quantitatively where evidence supports it.

## Preparation

Gather what the interface is trying to accomplish before reviewing.

## Criteria

- Hierarchy and action prioritization
- Text hierarchy and readability (line length, baseline, alignment)
- Cognitive load (working-memory limits)
- Interaction design (target sizing, focus, overlay behavior)
- Search and findability
